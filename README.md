# Анализ розничных продаж (Retail Sales Analysis)
Описание проекта
Этот проект — мое портфолио для позиции Аналитик данных. Я проанализировал датасет розничных продаж, чтобы ответить на ключевые бизнес-вопросы: как меняется выручка по месяцам и какие категории товаров приносят основную прибыль.
Инструменты
Excel: построение сводных таблиц и дашборда.
PostgreSQL (pgAdmin 4): написание SQL-запросов для проверки гипотез.
Файлы в репозитории
Dashboard.xlsx — интерактивный дашборд с выручкой по месяцам и категориям.
dashboard.jpg — скриншот дашборда для быстрого просмотра.
sql query tool.txt — SQL-запрос для расчета выручки и доли категорий.
sql table.jpg - скриншот запроса в pgAdmin4 для быстрого просмотра
dashboard analysis - краткая аналитика на основе дашборда.
